# 20M / 100M historical operating records

This directory preserves planning and operational decisions from the completed approximately-20M / 100M campaign that are no longer active project guidance.

These files document choices made for that run at the time. They are retained for historical reconstruction but must not override current status, accepted ADRs, current reference documents, or the current unified Kaggle runbooks.

Contents:

- `100m_console_output_decision.md` — presentation-only console decision for the former dedicated 100M entry point.
- `20m_microbatch_probe_decision_2026-08-05.md` — rollback/selection decision from the 100M microbatch qualification episode.
- `20m_100m_data_scaling_plan.md` — historical plan and final-identity pointer for the completed campaign.

Current reproducible operation is documented under `../../runbooks/20m_100m_runbook.md` and `../../runbooks/unified_kaggle_launcher.md`. Measured incidents and final results live under `../../evidence/20m_100m/`.
