# Archive

This directory preserves superseded plans, completed investigation handoffs, historical operating/design records, old qualification protocols, and one-off agent task specifications.

Archive rules:

- Nothing here is current authorization or active operating guidance.
- Commands and file paths may refer to code that has since been removed.
- Do not update an archived plan to match present behavior; write a current reference, runbook, or ADR instead.
- Completed measured outcomes belong in `../evidence/`, not here.
- Git history may hold redundant drafts that were intentionally retired after a canonical historical record was preserved.

Subdirectories:

- [`20m_qualification/`](20m_qualification/) — plans/procedures for the completed 20M/10M qualification campaign, including the August 4 launch amendment.
- [`20m_100m/`](20m_100m/) — historical planning and operating decisions from the completed 20M/100M campaign.
- [`gdn2_fla_investigation/`](gdn2_fla_investigation/) — completed August 8 FLA investigation handoff; current backend contract is in reference.
- [`post_training_s0_2026-08-06/`](post_training_s0_2026-08-06/) — historical S0/SFT design packet scoped to the then-planned 20M/100M post-training qualification.
- [`decision_registers/`](decision_registers/) — pre-ADR omnibus ledgers.
- [`agent_tasks/`](agent_tasks/) — completed one-off coding-agent briefs.

Use current status, accepted ADRs, and current reference/runbooks before consulting archive material.
