# Archive

This directory preserves superseded plans, old qualification protocols, historical decision registers, and one-off agent task specifications.

Archive rules:

- Nothing here is current authorization or an active runbook.
- Commands and file paths may refer to code that has since been removed.
- Do not update an archived plan to match present behavior; write a current reference, runbook, or ADR instead.
- Git history preserves removed executable implementations.
- Completed measured outcomes belong in `../evidence/`, not here.

Subdirectories:

- `20m_qualification/` — plans and procedures for the completed 20M/10M campaign.
- `decision_registers/` — pre-ADR omnibus ledgers.
- `agent_tasks/` — completed one-off coding-agent briefs.
